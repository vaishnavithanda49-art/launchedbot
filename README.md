# AI Meeting Assistant 🎙️

A Python-based application that listens to live meetings and converts speech to text.

## Features
- Live speech-to-text using Google Speech API
- Offline fallback using Whisper
- Responds to important keywords automatically

## Technologies Used
- Python
- Google Speech API
- OpenAI Whisper

## How to Run
1. Clone the repo: `git clone https://github.com/vaishnavithanda49-art/ai-meeting-assistant.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python main.py`
